## 1. Что это

Локальный HTTP-стенд сравнивает упрощенный клиент нативного `/api/generate` Ollama с клиентом, который проверяет завершение, сохраняет первый принятый ответ и возвращает его при повторе. Стенд сопровождает [статью на Хабре](https://habr.com/ru/companies/otus/articles/1101922/).

## 2. Что внутри

- `client.py` читает поток и сохраняет ответ по ключу операции.
- `experiment.py` запускает HTTP-стенд и сравнивает клиентов.
- `fixtures/` содержит два тела ответов Ollama, заголовки, параметры захвата и контрольные суммы.
- `capture.py` повторяет захват ответов в отдельный каталог.
- `expected.txt` описывает ожидаемые результаты всех проверок.

## 3. Требования

Python 3.9 или новее, Bash и `shasum`. Достаточно стандартной библиотеки Python. Тестовый сервер открывает временный порт на `127.0.0.1`.

## 4. Быстрый старт

```bash
./run.sh
```

Скрипт проверяет контрольные суммы записей и сравнивает результат с `expected.txt`.

## 5. Использование

| Сценарий | Упрощенный клиент | Клиент с проверками |
| --- | --- | --- |
| Фикстура `stop` | Принят | Принят |
| EOF до `done` | Принят | Отклонен |
| `error` после HTTP 200 | Принят | Отклонен |
| Фикстура `length` | Принят | Отклонен |
| Обрыв после `done`, без завершающего HTTP-чанка | Принят | Отклонен |
| Тело короче объявленного `Content-Length` | Принят | Отклонен |
| UTF-8 разрезан, следующий чанк содержит конец строки и новую строку | Принят | Принят |
| Превышен лимит байтов или числа объектов | — | Отклонен |
| Пустое резюме после `stop` | — | Отклонен |
| Повтор той же операции | 2 строки | 1 строка, первый ответ возвращен без Ollama |
| Тот же ключ, другое тело запроса | — | Конфликт |
| Две конкурентные попытки | — | 1 строка, обе вернули сохраненный ответ |

`stop.ndjson` и `length.ndjson` — тела HTTP 200 с типом `application/x-ndjson` от Ollama 0.32.15 с моделью `llama3.1:8b` Q4_K_M. Точные запросы, версия, digest модели и SHA-256 лежат в `fixtures/capture.json`, заголовки сохранены рядом. В первом ответе четыре строки NDJSON, во втором две. Стенд читает эти файлы и формирует нужные варианты потока при воспроизведении.

Для нового захвата запустите Ollama с `llama3.1:8b`. Команда записывает тела, заголовки протокола и метаданные в новый каталог. Временные метки и длительности при повторе меняются.

```bash
python3 -B capture.py http://127.0.0.1:11434 fresh-capture
```

## 6. Ограничения

- Стенд проверяет нативный `/api/generate` через `urllib.request` и `http.client`. Сравнение относится к двум реализациям в репозитории.
- Для этого приложения результат с `done_reason: length` неполный. Полнота потока и качество текста проверяются отдельно.
- Клиент ограничивает размер строки, размер тела и число объектов. Тайм-аут отдельной блокирующей операции задан в `urlopen`. Общий дедлайн и отмену задает вызывающий сервис.
- Технический повтор использует исходные байты JSON. Для `summarize` нужно выделенное соединение SQLite в стандартном транзакционном режиме, без открытой транзакции. При гонке двух запросов модель может отработать дважды, уникальный ключ защищает сохранение. Внешние побочные эффекты требуют отдельной защиты.
